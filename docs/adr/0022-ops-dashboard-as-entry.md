# 0022. 運用ダッシュボードを入口にし、評価ダッシュボードは /eval に移す

- 状態: 採用
- 日付: 2026-09-26
- 関連: [architecture.md](../architecture.md)

## 背景と課題

利用者が主に使うのは運用ダッシュボードになった。企業へのデモも、運用の流れから見せたい。

## 決定

- `/` は `/ops`（運用ダッシュボード）に移す。
- 評価ダッシュボードは `/eval`・`/eval/apps/:name`・`/eval/apps/:name/run` にする。以前の `/apps/...` はクエリを保ったまま新しい URL に移す（ブックマークを切らさない）。
- ツールは `/tools/...` のまま。
- ヘッダーの接続先の切替は `/eval` と `/tools` だけで出す（運用は設定の接続先で動くため）。

## 結果

- 良い点: 開いてすぐ運用の流れが見える。
- 悪い点: 評価ダッシュボードへは左ペインから移る必要がある。
