# 0004. 精度は学習ではなく閾値の調整で上げる

- 状態: 採用
- 日付: 2026-09-26
- 関連: [jev.md §8](../jev.md#8-閾値の考え方このプロジェクトの既定)

## 背景と課題

自動で振り分ける範囲を広げたいが、誤りは増やしたくない。
「学習ループ」をどう作るかが論点になった。選択肢は、モデルを学習し直す方法と、使い方を調整する方法の 2 つである。

## 検討した選択肢

1. 人の確認結果でモデルを学習し直す（ファインチューニング）
2. **人の確認結果を正解として、閾値を調整する**
3. 閾値を固定のまま運用する

## 決定

選択肢 2 を採用する。

- **正解として使う件:** 人が確認・修正した件、抜き取り確認の結果、デモの想定ラベル。
- **調整の仕方:** 閾値を 0.50〜0.99 で動かしたときの「自動で振り分ける割合」と「その誤り率」の曲線を描く。そのうえで、目標の誤り率を満たす一番低い閾値を提案する。
- **提案しない場合:** 件数が少ない（20 件未満）とき、または自動で振り分ける件が 10 件未満になるとき。誤り率が偶然 0 になりやすいため。
- **反映:** 人が決める（自動では変えない）。分類ごとの閾値にも反映できる。

## 結果

- 良い点
  - モデルに手を入れずに、誤り率と自動化率の釣り合いを説明できる形で決められる。
  - Jev は較正（確率の当たり具合）を前提に作られているので、閾値で使い分けやすい。
- 悪い点
  - 正解の付いた件がたまるまで提案できない。そのため、抜き取り確認で正解を集め続ける。
