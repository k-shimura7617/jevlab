# 0024. エスカレーションの完了は、エスカレーションのスレッドだけで知らせる

- 状態: 採用
- 日付: 2026-09-26
- 関連: [ADR-0013](0013-slack-socket-mode.md)、[ADR-0014](0014-close-routed-items-in-jevlab.md)

## 背景と課題

エスカレーションの件を完了にすると、エスカレーションのスレッドへの返信に加えて、分類のチャンネル（#cs-クレーム など）にも「対応完了」を投稿していた。
同じ件の知らせが 2 か所に出て、分類のチャンネルが完了の投稿で埋まる。

## 決定

- エスカレーションの件の完了は、エスカレーションの親の投稿のスレッドへの返信と ✅ だけで知らせる。
- 分類のチャンネルには投稿しない。
- 振り分けた件の完了は、これまでどおり元の投稿のスレッドで知らせる（ADR-0014）。

## 結果

- 良い点: 1 件の経緯が 1 つのスレッドにまとまる。分類のチャンネルが読みやすい。
- 悪い点: 分類のチャンネルだけを見ている人は、エスカレーションの完了に気づかない。
