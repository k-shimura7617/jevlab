# 0016. 個人情報のガードに「規則だけ」のモードを用意する（Kev の ON/OFF）

- 状態: 採用
- 日付: 2026-09-26
- 関連: [ADR-0002](0002-kev-pii-guardrail.md)

## 背景と課題

- Kev は CPU で動くため遅く、個人情報のガードが処理全体の詰まりになっていた。
- デモでは、ガードそのものを外した比較もしたい。

## 検討した選択肢

1. Kev をやめて規則だけにする
2. **設定で切り替える:「Kev で判定する」（オフで規則だけ）と「有効にする」（オフでガードなし）**
3. Kev の代わりに Jev でガードする（マスク前の本文が外に出るので不可）

## 決定

選択肢 2。

- **規則だけ（`guard.use_model = false`）**
  - Kev を呼ばない。
  - 規則で拾った氏名などの候補は、すべて個人情報として扱ってマスクする（安全側）。
  - 候補外の残りの確認（`pii_leftover`）はしない。
  - 経過に「規則だけで判定」と残す。左ペインは「個人情報の確認（規則のみ）」と表示する。
- **ガードなし（`guard.enabled = false`）**
  - 元の本文のまま Jev に送る（デモ用）。画面で強く警告する。
  - この件は Slack に番号とリンクだけを送る（見出しを伏せられないため）。

## 結果

- 良い点: Kev が遅い・止まっているときも処理が進む。
- 悪い点: 規則だけでは、形で決まらない個人情報（敬称なしの氏名など）を見逃しうる。伏せすぎも増える。
