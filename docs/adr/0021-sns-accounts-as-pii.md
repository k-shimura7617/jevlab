# 0021. SNS のアカウント名とプロフィールの URL を個人情報として扱う

- 状態: 採用
- 日付: 2026-09-26
- 関連: [ADR-0002](0002-kev-pii-guardrail.md)、[ADR-0020](0020-measure-guard-with-reviews-and-miss-reports.md)

## 背景と課題

- 「@kanako_0503 に DM を」のような SNS のアカウント名が検出されず、Jev に届いた。
- SNS のアカウント名は、それだけで、または他の情報と合わせて個人を特定できることがあり、個人情報保護法の個人情報に当たりうる（メールアドレスと同じ考え方）。
- 一般の URL（会社のサイト・商品のページ）は個人情報ではない。

## 決定

- 種類「SNS アカウント」（`sns_account`）を追加する。規則で確定し、既定の方針はマスク。
- 拾うもの:
  - SNS のプロフィールの URL（x.com/…、instagram.com/…、tiktok.com/@… など）
  - @から始まる名前のうち、近くに SNS の話（DM・フォロー・アカウントなど）があるもの
- 拾わないもの: 一般の URL、SNS の決まったページ（x.com/home など）、メールアドレスの @、「@500円」のような数字だけのもの。

## 結果

- 良い点: 見逃しの多い種類を、モデルに頼らず確実に伏せられる。
- 悪い点: 文脈による判定なので、SNS の話がない @名前は拾わない。最終的な範囲は会社の方針で決める。
