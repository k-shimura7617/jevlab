# 0026. 監査ログの CSV には本文と個人情報を出さない

- 状態: 採用
- 日付: 2026-09-26
- 関連: [ADR-0002](0002-kev-pii-guardrail.md)

## 背景と課題

- 情報システム部門・監査部門に、経過（監査ログ）を期間や件で絞って CSV で渡したい。
- 経過の記録には、受信の差出人（名前・アドレス）、メモの本文、ガードの候補の文字列など、個人情報が入っている。
- CSV はいったん外に出ると、取り消しも管理もできない。

## 決定

- 出力するのは「いつ・どの件で・何が・誰（主体）が・どう変えたか」だけにする。列は日時（日本時間）・件・種類・主体・内容・変更前・変更後・モデル・所要時間。
- 本文と個人情報は出さない。「含める」選択肢も作らない。
  - 受信の記録の差出人は「差出人は伏せる」に置き換える。メモは「メモを追加（本文は伏せる）」とだけ書く。
  - 経過に付いた詳しいデータ（ガードの候補の文字列など）は出さない。
  - 念のため、内容の文は Slack の見出しと同じ規則で個人情報の候補をすべて伏せる。
- 中身を確かめたいときは、件の番号で jevlab の中を見る。
- 書き出したこと自体（日時・条件・行数）を記録し、画面に出す。
- 文字コードは UTF-8（BOM 付き）と Shift_JIS を選べる。

## 結果

- 良い点: 監査に渡しても、個人情報が外に出ない。
- 悪い点: ログインがないため、主体は「人」までしか分からない（誰が操作したかは取れない）。操作者の記録は、社内の認証（SSO）を前に置く段階で検討する。
