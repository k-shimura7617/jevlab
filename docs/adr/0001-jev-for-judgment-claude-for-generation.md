# 0001. 判定は Jev、文章の生成は Claude に分ける

- 状態: 採用
- 日付: 2026-09-26
- 関連: [jev.md](../jev.md)、[0009](0009-claude-cli-generator.md)

## 背景と課題

このアプリでは、次の 2 種類の AI の仕事が必要になる。

- 判定: 問い合わせの分類、個人情報か、優先度の観点、言い方の良し悪し
- 生成: 言い方チェックの書き換え案

Jev は型の決まった判定と確率を返すモデルで、文章は生成しない。
LLM に判定させて出力を解析する方法もあるが、速さ・料金・確率が使えるかの点で Jev と差がある。

## 判断の基準

- 判定の結果を、閾値・並べ替え・集計にそのまま使えること（確率が要る）
- 速さと料金（入力 $0.042 / 100 万トークン、出力は無料）
- 出力の形が保証されること（解析に失敗しない）

## 検討した選択肢

1. 判定も生成も LLM（Claude）で行い、JSON を解析する
2. **判定は Jev、生成は Claude に分ける**
3. 生成も Jev の選択（Choice）で代用する（定型文から選ぶ）

## 決定

選択肢 2 を採用する。

- 判定はすべて Jev の Choice / Score / Noul で行う。
- 自由な文章が本当に必要な箇所（書き換え案）だけ、生成器（Claude）を使う。
- 生成した文章は、もう一度 Jev で判定して比べる。生成の結果を判定で確かめる、という関係にする。

## 結果

- 良い点
  - 判定の結果は確率つきで扱える。閾値・並べ替え・集計がコードだけで書ける。
  - 1 回の問い合わせで多数の観点を並列に判定できる。
- 悪い点
  - 判定の理由は説明されない。画面では観点ごとの確率と、文ごとのハイライトで説明を補う。
  - 生成には別の仕組み（Claude）が要る。
