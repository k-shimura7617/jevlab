# 0019. ブロックした件には、Kev の参考の判定を添える（自動では使わない）

- 状態: 採用
- 日付: 2026-09-26
- 関連: [ADR-0002](0002-kev-pii-guardrail.md)、[ADR-0016](0016-guard-rules-only-mode.md)

## 背景と課題

カード番号・口座番号を含む件はブロックして Jev に送らない。そのため分類も担当の推定もなく、エスカレーションの一覧で「振り分け前」のまま並び、人が一から判断していた。

## 決定

- ブロックして人に回す件は、Kev（ローカル。元の本文を読んでよい）で分類と担当の推定を出し、`kev_reference` に残す。
- 画面では「参考（Kev）」として表示するだけ。自動の振り分け・割り当てには使わない。
- 一覧の表示は「個人情報のため Jev 未送信」にする。
- Kev が使えないとき、または規則だけのモードのときは行わず、経過に残す。
- Jev にも Slack にも、この判定は送らない。

## 結果

- 良い点: ブロックした件も、人が分類・担当を決める手がかりがある。
- 悪い点: Kev の処理がその分増える（1 件ずつしか動かないため、他の件が待つ）。
